# Lab: Network Protocol Analysis with Wireshark

## 🎯 Objective
To capture and analyze network traffic using Wireshark.

## 🛠 Tool Used
- Wireshark

## 📌 Steps Performed
1. Started live packet capture
2. Applied protocol filters (TCP, UDP, HTTP)
3. Inspected packet headers and payloads
4. Saved traffic as PCAP files

## 🧠 Observations
- Network traffic reveals communication patterns
- Filters simplify packet analysis
- PCAP files are useful for forensic investigations


## ✅ Outcome
Developed practical skills in packet capture and network traffic analysis.
