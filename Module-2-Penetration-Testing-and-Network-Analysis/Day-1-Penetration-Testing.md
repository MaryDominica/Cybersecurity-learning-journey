# Day 1: Penetration Testing & the Attack Phase

## 🔐 What is Penetration Testing?
Penetration testing is the process of simulating real-world cyberattacks to identify vulnerabilities before malicious actors exploit them.

## ⚔️ The Attack Phase
The attack phase focuses on actively exploiting discovered weaknesses. Key actions include:

- Running exploits
- Bypassing security controls
- Gaining elevated privileges
- Performing post-exploitation activities


## 📊 NIST Vulnerability Classifications
According to NIST, vulnerabilities fall into eight major categories:

1. Misconfigurations
2. Kernel flaws
3. Insufficient input validation
4. Symbolic link flaws
5. File descriptor errors
6. Race conditions
7. Buffer overflows
8. Incorrect file and directory permissions

Understanding these categories helps security professionals systematically assess and mitigate risks.


## 🧠 Key Learning
Penetration testing is not just about tools, it requires an attacker mindset to effectively defend systems.
