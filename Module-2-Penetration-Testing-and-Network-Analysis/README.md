# Module 2: Penetration Testing & Network Analysis

## 📌 Overview
This module focuses on penetration testing fundamentals, vulnerability classifications, port scanning techniques, and network protocol analysis using industry-standard tools such as Nmap and Wireshark.

The goal is to understand how attackers exploit systems and how defenders detect and analyze malicious network activity.

## 📖 Topics Covered
- Penetration testing and the attack phase
- NIST vulnerability classifications
- Penetration testing tools by functionality
- Port scanning techniques
- Network protocol analyzers
- Wireshark and packet capture formats
- Practical lab exercises

## 🧪 Labs Completed
- Port scanning using penetration testing tools
- Port scanning with Nmap
- Network protocol analysis using Wireshark

## 🛠 Tools Used
- Nmap
- Wireshark
- Network protocol analyzers
- PCAP and PCAPNG file formats

## 🎯 Key Takeaway
This module strengthened my understanding of both offensive security techniques and defensive network analysis, reinforcing the importance of proactive security testing.
